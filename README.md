## 📖 Sobre o Projeto

O **Apanhador de Estrelas** é um projeto interativo onde o objetivo principal é coletar o máximo de estrelas antes que o tempo acabe ou evitando obstáculos pelo caminho. Ideal para demonstrar conceitos de desenvolvimento de jogos, manipulação de eventos e lógica de programação.

---

## 🚀 Funcionalidades

- ⭐️ **Coleta de Estrelas:** Elementos interativos gerados na tela para o jogador capturar.
- ⏱️ **Sistema de Pontuação / Tempo:** Acompanhamento de score em tempo real.
- 🎮 **Controles Simples:** Movimentação intuitiva via teclado ou mouse.
- 🎨 **Interface Amigável:** Design simples e dinâmico.
